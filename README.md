# Walk Through and Auto Pilot

## Live demo

[Open Walk Through on GitHub Pages](https://pxgrid-labs.github.io/walk-through/)

3D空間を歩いて、コンビニの店内を見て回るウォークスルーデモです。

- W / A / S / D キーで自由に移動し、スペースキーでジャンプできます。
- タッチデバイスではジョイスティックで移動できます。
- 左上のボタンからオートパイロットモードに切り替えられます。

避難経路シミュレーション向けの3D素材を見つけにくかったため、店内経路のデモとして制作しました。この体験は、物件内の案内、避難経路シミュレーション、商品やサービスの世界観を伝えるブランディングなどに応用できます。インストール不要で、リンクから利用者に届けられます。
